Standar Kepatuhan Bank Indonesia (KUPVA BB)

Pengawasan transaksi valuta asing: Ambang Batas USD 10.000, PEP & EDD, serta Skrining DTTOT/DPPSPM

  • Ambang batas valas ≥ USD 10.000

    Transaksi setara USD 10.000 ke atas wajib melampirkan nomor dokumen underlying (tiket, invoice, medis, pendidikan).

  • PEP & EDD Risiko tinggi

    Nasabah PEP (Politically Exposed Person) wajib ditelusuri sumber dana dan tujuan transaksinya, dengan persetujuan Direksi.

  • DTTOT / DPPSPM Blokir

    Nama nasabah diperiksa saat kasir mengetik. Jika cocok, transaksi diblokir seketika (freeze without delay).

Uji skrining nama

Cek satu nama ke daftar DTTOT / DPPSPM tanpa membuat transaksi.

Panduan Integrasi Google Sheets (1 Menit Siap)

Data transaksi langsung dicatat ke tab sheet nomor tanggal ("1", "2", dst). Transaksi Beli otomatis mengisi tabel BUY, dan transaksi Jual mengisi tabel SELL FOREIGN CURRENCY tanpa mengubah rumus saldo.
  1. 1
    Buka Google Sheets & Apps Script: Buka spreadsheet Oktober MC Skyline, lalu di menu atas klik Ekstensi (Extensions) > Apps Script. Buka Spreadsheet di Tab Baru
  2. 2
    Salin & Tempel Kode Script: Hapus isi kode di dalam Code.gs, lalu tempelkan kode webhook di bawah ini:
    google-apps-script.js 
    Memuat kode script...
  3. 3
    Terapkan Sebagai Web App (Deploy):

    - Klik tombol biru Terapkan (Deploy) di pojok kanan atas > pilih Penerapan baru (New deployment).
    - Klik ikon roda gigi > pilih jenis Aplikasi Web (Web app).
    - Jalankan sebagai (Execute as): Saya (Me).
    - Siapa yang memiliki akses (Who has access): Siapa saja (Anyone).
    - Klik Terapkan (Deploy), berikan izin akses Google jika diminta, lalu salin URL Aplikasi Web yang berakhiran /exec.

  4. 4
    Tempelkan URL di POS, Simpan & Tes: Tempelkan URL tersebut ke kolom URL Web App Google Apps Script di tab Integrasi Google Sheets, klik tombol Simpan URL & Pengaturan (tersimpan permanen selamanya), lalu klik Tes Koneksi. Selesai!

Panduan Printer Kasir (Paired / Driver)

🔵 Kasus 1: Printer Berstatus "Paired" di Windows Bluetooth

Di Windows, printer Bluetooth yang berstatus Paired beroperasi lewat Virtual COM Port (Bluetooth Serial) atau terdaftar sebagai Printer Windows.

Cara Mencetak:
Opsi A (Paling Mudah): Klik tombol Cetak USB / Driver. Di jendela cetak Chrome, pilih nama printer Anda di Destination.
Opsi B (Direct ESC/POS): Klik Hubungkan Serial / COM, lalu pilih port COM printer Bluetooth Anda. Struk akan keluar langsung tanpa dialog cetak.
🔌 Kasus 2: Printer Menggunakan Kabel USB
Jika Driver Windows Sudah Terpasang: Port USB dikunci eksklusif oleh Windows. Cukup klik tombol Cetak USB / Driver.
Jika Tanpa Driver Windows: Klik Hubungkan USB untuk mengirim data langsung via WebUSB.
⚙️ Tips Cetak Rapi di Jendela Browser (Cetak USB / Driver):
  • Destination (Tujuan): Pilih printer thermal Anda (contoh: POS-58, POS-80, atau nama printer kasir Anda).
  • Paper Size (Ukuran Kertas): Pilih Roll Paper / 80mm / 58mm.
  • Margins (Margin): Pilih None (Tidak Ada) agar struk pas dan tidak terpotong.
  • Headers and footers: Hilangkan centang agar URL dan tanggal website tidak tercetak di struk.
